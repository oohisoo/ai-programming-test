## 데이터 (12주차 실습)

### 사용 데이터
- scores_2026.csv: 원본 성적 데이터 114행 5열
- scores_2026_cp949.csv: CP949 인코딩 성적 데이터
- mini.csv: 손계산 검증용 데이터 10행

### 데이터 정제
- 점수 결측값 6행 제거
- 중복 데이터 4행 제거
- 반과 과목 이름의 앞뒤 공백 제거
- 점수 범위를 벗어난 데이터 4행 제거
- 최종 데이터 100행 확보

### 데이터 분석
- 수학 과목 필터링
- 반별 평균 및 과목별 반별 평균 계산
- 반별 개수, 평균, 중앙값, 최댓값 계산

### 검증
- 반별 점수 합계와 전체 점수 합계 비교
- 반별 데이터 개수와 전체 데이터 개수 비교
- mini.csv 손계산 결과와 코드 실행 결과 비교
- pytest 테스트 4개 통과
- 의도적인 오류 발생을 통한 테스트 기능 확인

### 실행 방법
python analysis.py

### 테스트 방법
python -m pytest -q test_analysis.py
